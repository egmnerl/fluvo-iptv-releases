# Fluvo IPTV — indirmeler

Bu depo yalnızca **Fluvo IPTV** uygulamasının kurulum dosyalarını dağıtmak içindir. Kaynak kodu içermez.

**En son sürüm:** [Releases → Latest](https://github.com/egmnerl/fluvo-iptv-releases/releases/latest) · Tanıtım sitesi: [fluvoiptv.com](https://fluvoiptv.com)

## Hangi dosyayı indirmeliyim?

| Cihaz | Dosya |
|---|---|
| Android telefon / tablet (Android 8.0+) | `Fluvo-IPTV-<sürüm>-telefon.apk` |
| Android TV (Android TV 8.0+) | `Fluvo-IPTV-<sürüm>-tv.apk` |
| Emin değilseniz (her Android cihazda çalışır, daha büyük) | `Fluvo-IPTV-<sürüm>.apk` |
| Mac (macOS 14+) | `Fluvo-IPTV-macOS-<sürüm>.zip` |
| iPhone / iPad | Yakında App Store'da |

- **Android:** Kurarken "bilinmeyen kaynaklardan yükleme" iznini bir kez vermeniz gerekir.
- **Mac:** İlk açılışta uyarı çıkarsa uygulamaya sağ tıklayıp "Aç" deyin.
- Her sürümün notlarında dosyaların SHA-256 özetleri yer alır.

## Yasal not

**Fluvo IPTV yalnızca bir oynatıcıdır; içerik, kanal veya abonelik sağlamaz.** Kendi yasal kaynaklarınızı eklersiniz. Uygulamada hazır kanal listesi, yayın adresi veya abonelik bağlantısı yoktur. Giriş bilgileri yalnızca cihazınızda şifreli saklanır.
